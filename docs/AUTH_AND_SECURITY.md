# 🔐 Duck Academy — Автентифікація, Сесії та Безпека (SCRUM-50)

> **SCRUM-50**: [Academy L1] Реєстрація, логін і гостьовий режим.

Цей документ описує архітектуру авторизації, захист сесійних токенів, політику згоди батьків для дітей та режим гостьового перегляду.

---

## 📋 1. Вимоги до паролів та облікових записів

* **Username**: від 3 до 24 символів (дозволені літери латиниці, цифри та нижнє підкреслення).
* **Password**:
  * Мінімальна довжина: **8 символів**.
  * Хешування: PBKDF2 з 10,000 ітераціями, SHA-512 та унікальною криптографічною сіллю (Salt) для кожного користувача.
  * Паролі **ніколи** не зберігаються у відкритому вигляді, не записуються в LocalStorage і не виводяться у системні логи.
* **Згода батьків (Parent Consent)**:
  * Для ролі `child` обов'язковим є чекбокс підтвердження від батьків.
  * Платформа не збирає номери телефонів, домашні адреси чи фінансові дані неповнолітніх (Full COPPA/GDPR-K compliance).

---

## 🍪 2. Безпека сесій (Session Management)

* Сесії зберігаються у захищеному cookie `duck_academy_session` з прапорцями:
  * `HttpOnly: true` (недоступні для крадіжки через XSS).
  * `SameSite: Lax` (захист від CSRF-атак).
  * `Secure: true` у продакшені (передача виключно через HTTPS).
* Підпис токена здійснюється алгоритмом **HMAC-SHA256**.
* При валідації токена застосовується функція `crypto.timingSafeEqual`, що унеможливлює таймінг-атаки на відновлення сигнатури.

---

## 👤 3. Гостьовий режим (Guest Mode)

* Будь-який відвідувач може оглянути каталог уроків, треки та платформу без створення акаунта.
* У гостьовому режимі:
  * На сторінці відображається інформаційний банер із пропозицією увійти.
  * Прогрес зберігається лише локально в браузері.
  * Для синхронізації між пристроями та отримання офіційного сертифіката пропонується безкоштовна реєстрація.

---

## 🚪 4. Вихід із системи (Logout)

При виклику `POST /api/academy/auth/logout`:
1. Cookie `duck_academy_session` видаляється з браузера шляхом встановлення `maxAge: 0`.
2. Клієнтський стан скидається до гостьового профілю (`role: 'guest'`).
3. Приватні дані портфоліо та адмін-панелі стають недоступними.
