# 🧪 Duck Verse — QA Smoke Tests (SCRUM-24)

> **Документ**: Матриця та інструкція для регулярного smoke-тестування активних ігор хабу, перевірки керування, адаптивності та повернення до головного меню.

---

## 📋 1. Як запускати тести локально

Запуск усіх автоматизованих smoke-тестів:
```powershell
npm test
```
або через прямий виклик Node.js test runner:
```powershell
node --test tests/games_smoke.test.mjs
node --test tests/flappy_game.test.mjs
```

## 🔄 3. Очищення ресурсів при виході
Кожен рушій гри реалізує метод `.stop()`, який:
- Зупиняє `requestAnimationFrame` та `setInterval`.
- Відключає обробники подій `keydown`, `keyup`, `pointerdown`, `pointermove`.
- Зберігає поточний стан прогресу та баланс QuackCoins у `localStorage`.
- Повертає скрол сторінки до вихідного стану (`overflow: auto`).
