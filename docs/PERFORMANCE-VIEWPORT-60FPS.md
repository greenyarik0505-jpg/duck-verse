> **Призначення документу**: Фіксація архітектури фіксованого 60 FPS кроку фізики (Fixed Timestep), узгодження з uncapped-дисплеями (120Hz, 144Hz, 240Hz) та оптимізація панелі керування гри під мобільні екрани (320px – 390px).

## 🎯 1. Архітектура 60 FPS фізики (Fixed Timestep Accumulator)
Усі ігри хабу (Geometry Dash, Galactic Invaders, Flappy Duck) використовують детермінований акумулятор часу:
```javascript
const FIXED_STEP = 1000 / 60; // 16.6667ms — фіксований крок симуляції
this.accumulator += frameDelta;

let steps = 0;
while (this.accumulator >= FIXED_STEP && steps < 4) {
    this.update(); // фізика завжди рухається з кроком 60 FPS
    this.accumulator -= FIXED_STEP;
    steps++;
}
```

### Чому це критично:
1. **Незалежність від частоти монітора**: На моніторах 60Hz, 120Hz чи 144Hz швидкість куба, висота стрибків, обертання та хітбокси шипів є абсолютно однаковими.
2. **Захист від спіралі смерті (Spiral of Death)**: Обмеження `steps < 4` захищає від підвисання при перемиканні вкладок браузера.
3. **Чесна телеметрія**: У `GameModal.jsx` телеметрія чітко показує:
   `⚡ 60 FPS Lock (144Hz) | < 16ms`
   Користувач бачить, що фізика працює на стабільних 60 FPS, а екран оновлюється з нативною частотою його дисплея без розривів (tearing).

## 📱 2. Адаптивність Game HUD для Mobile (320px – 390px)

| Viewport | Поведінка панелі HUD | Керування |
|---|---|---|
| **Desktop (>= 768px)** | Повна панель, всі текстові підказки (`[R] Заново`, `[Esc] До хабу`) | Миша, клавіатура (`Space`, `R`, `M`, `F`, `Esc`) |
| **Tablet (640px – 768px)** | Компактний прогрес-бар (140px), скорочені відступи | Тач або клавіатура |
| **Mobile (420px – 640px)** | Приховані текстові лейбли `.gaming-btn-label`, кнопки стають квадратними іконками (`🔄`, `🔊`, `⛶`, `✖`) | Сенсорні натискання |
| **Ultra-Compact (<= 420px / 320px)** | Статистика (`Спроба`, `Рекорд`) переноситься у другий компактний рядок, всі 4 функціональні кнопки залишаються видимими та доступними для тапу | Touch-friendly (мінімальна зона тапу 36px) |
